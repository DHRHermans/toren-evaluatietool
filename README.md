# Torenlab — GitHub Pages

Evaluatieapp bij De draagkracht toren. Werkt zelfstandig, zonder ChatGPT of extra installatie.

## Op GitHub Pages zetten
1. Pak dit ZIP-bestand uit.
2. Maak op GitHub een repository, bijvoorbeeld torenlab.
3. Kies Add file → Upload files. Upload index.html, README.md en .nojekyll naar de hoofdmap (geen extra bovenliggende map). Het bestand .nojekyll is optioneel voor deze app.
4. Klik op Commit changes.
5. Open Settings → Pages.
6. Kies onder Build and deployment: Deploy from a branch.
7. Kies de branch main en de map / (root). Klik Save.
8. Wacht tot GitHub Pages de site heeft gepubliceerd en open de link die GitHub toont.

Je kunt index.html ook rechtstreeks openen op je computer om de app offline te gebruiken.

## Gegevens bewaren
De evaluaties worden uitsluitend in de browser op het gebruikte toestel bewaard. Ze worden niet naar GitHub gestuurd en zijn niet automatisch zichtbaar op andere toestellen. Download geregeld een back-up. Herstel die back-up in de app op een ander toestel.

Bestaande gegevens van de ChatGPT-site gaan niet automatisch mee naar GitHub Pages: klik op de oude site op Back-up en op de nieuwe site op Herstellen.

## Gebruik
- Voeg groepen en namen toe.
- Voer de torenhoogte in bij criterium 1: minimaal 40 cm.
- Beoordeel de overige constructiecriteria.
- Registreer de draagkracht in stappen van 50 g. De grote timerpopup telt 10 seconden af en geeft drie pieptonen. Start de timer zelf met de knop om geluid in de browser mogelijk te maken. Zorg dat volume aan staat.
- Beoordeel het technisch proces per leerling.
- Exporteer naar CSV of druk het overzicht af als PDF.

Er is geen puntenverdeling opgelegd: aantallen behaalde criteria zijn geen rapportcijfer.
